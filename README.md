# LEETECH & AUTOS

A premium, responsive Nigerian tech and auto storefront built with React, TypeScript, Vite, Tailwind CSS v4, Framer Motion, and Lucide icons. The visual direction combines classic editorial typography, rich charcoal and burgundy, authentic photography, and restrained cinematic motion.

## Run

```sh
npm install
npm run dev
```

## Verify

```sh
npx tsc --noEmit
npx playwright install --with-deps chromium
npx playwright test
npm run build
```

## Features

- Cinematic, full-bleed hero with genuine automotive photography.
- A prominent, tabbed Latest Devices showcase immediately after the hero, featuring iPhone 18 Pro Max, iPhone 18 Pro, Galaxy S26 Ultra, and the announced 14-inch MacBook Pro with M6.
- Latest-device details use official Apple and Samsung images and verified manufacturer specifications. Finish and configuration choices are included in a WhatsApp enquiry to LEETECH; no unconfirmed Nigerian prices or stock are invented.
- Real photographer-shot collection and lifestyle images from Pexels, plus original manufacturer-hosted imagery for the latest devices. No images are AI-generated by LEETECH.
- On-site photography credits with links to every original source.
- Eight browsable categories, expanded product collections, and live product search.
- Product quick views, a persistent wishlist, and a persistent shopping bag with quantity controls.
- Validated demo checkout and vehicle inspection request forms.
- A live weekly deal countdown, customer testimonials, newsletter preferences, and helpful policy dialogs.
- Responsive navigation, keyboard-accessible dialogs, focus management, and reduced-motion support.
- Genuine photography and licensed typefaces load from the Pexels and Google Fonts CDNs. An internet connection is required for product images and custom fonts.

## Project Files

- `src/App.tsx`: homepage, product data, and storefront interactions.
- `src/index.css`: responsive interaction primitives and base design system.
- `src/storefront.css`: classic editorial storefront, refined typography, and responsive luxury styling.
- `src/data/photography.json`: traceable image manifest with photographer credits and original source URLs.
- `src/data/latest-devices.ts`: manufacturer-verified latest-device data, exact official image URLs, specifications, colourways, and release notes.
- `src/components/LatestDevices.tsx`: keyboard-accessible homepage showcase and device enquiry detail view.
- `src/components/latest-devices.css`: responsive latest-device presentation.
- `public/leetech-logo.svg`: full LEETECH & AUTOS logo (car, red phone, wordmark and tagline) with a transparent background, made for dark backgrounds. The About dialog offers SVG downloads and transparent 2400px PNG exports of both versions. The PNGs are rendered in the browser from the SVGs.
- `public/leetech-logo-compact.svg`: the same logo without the tagline, used in the header.
- `public/leetech-logo-light.svg`: the logo recoloured for light backgrounds (charcoal wordmark, glossy red phone, silver car), also transparent.
- `public/favicon.svg`: the car-and-phone mark on the brand black.
- `src/assets/logo/`: the logo files the app actually uses. They are bundled into the page, so they cannot go missing. `public/` holds identical copies for external use.
- `scripts/build-logo.mjs`: regenerates the SVG logo files (`node scripts/build-logo.mjs`). The wordmark and tagline are drawn as outlines, so no font is needed.
- `src/data/photography.json`: genuine, photographer-shot stock photographs and source credits from Pexels.
- `DESIGN-NOTES.md`: reference research and visual design decisions.
- `tests/storefront.spec.ts`: browser-level interaction and responsive layout tests.

## Before Launch

The logo files are a vector redraw of the supplied LEETECH & AUTOS logos (dark and light versions), not the original image files, so fine details of the car outline differ slightly. To use the original artwork instead, replace `public/leetech-logo.svg` (and `leetech-logo-compact.svg` if you have a version without the tagline) with your exported SVG or PNG.

This is a complete interactive frontend, not a live order-processing service. Checkout, inspection requests, cart items, saved products, and newsletter preferences use browser local storage. No payments are processed or email subscriptions transmitted. Forms clearly describe demo behaviour.

Connect a real product and inventory source, order API, payment provider, inspection booking service, newsletter platform, and customer support channel before accepting purchases. Replace the generic social platform links with the business's verified profiles.

Products, prices, customer reviews, and service statements are presentation samples. Every photograph is real, but the photographs are representative stock photography rather than this business's own inventory photos. Confirm exact models, specifications, condition, fitment, availability, delivery terms, and policies before publishing. Replace stock photographs with original photographs of actual inventory where appropriate.

The image sources are listed in the on-site Photography credits dialog and `src/data/photography.json`. Photographs are used under the [Pexels License](https://www.pexels.com/license/). Product images are delivered by Pexels' image CDN; customers need an internet connection to load them.

The Latest Devices section uses original manufacturer-hosted product imagery, separately credited to Apple and Samsung. These images remain the property of their owners, not Pexels-licensed stock. Review applicable brand/media-use permissions before commercial publication. Manufacturer release dates are not promises of LEETECH inventory or Nigerian delivery dates. MacBook Pro with M6 is labelled as announced, with Apple's stated November 6, 2026 availability date.

Manrope, Space Grotesk, and Instrument Serif are distributed under the SIL Open Font License. Their license files are included in `public/fonts/`.
